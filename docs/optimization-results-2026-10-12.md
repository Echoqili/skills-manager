# 功能流程优化与验证记录

## 已完成

- 本地搜索先展示，AI 推荐独立请求。AI 超时或失败不影响本地结果。
- 搜索与分类共享请求序号和取消信号；迟到的请求无法覆盖最近一次操作。
- 首页分页读取全部技能，加载期间显示进度，不再截断前 300 条。
- 分类与关键词组合筛选，切换来源重新显示对应内容；GitHub 空关键词有操作引导。
- 初始化并行加载独立数据。HTTP 错误、超时和详情加载失败提供明确反馈及重试入口。
- 详情、参考资料、清单和打包统一使用 registry 标识。旧名称只在没有歧义时接受。
- 详情返回保留页码、滚动位置和精选专题内容；离开详情后迟到响应不会重设详情状态。
- 安装指引使用 `python cli/sm.py install` 和实际命名空间，说明执行目录及 `-t` 目标目录选项。个人技能提供下载解压指引。
- 清单加载校验结构、去重并迁移可唯一识别的旧名称；失效或有歧义的条目可移除。
- 打包与导入防重复提交，操作期间按钮显示忙碌状态。打包失败保留清单。
- 打包前校验全部目录和技能正文；失效或有歧义的选择明确拒绝。同名技能拥有不同归档目录，生成目录避开现有技能名，包文件名避免同秒覆盖。
- 导入、删除、恢复和发布成功后同步列表、统计与分类，保留当前筛选条件。
- 相关元数据按纯文本转义；复制命令失败显示手动复制提示。
- 新增流程测试已加入 GitHub Actions。
