# 角色管理与隐藏功能部署记录

## 已实现并上线

- 普通用户与管理员遵守分配的业务权限；超级管理员拥有全部权限。
- 空权限数组表示无权限，管理员身份不再绕过业务权限。
- 普通用户审批与权限管理在 /admin；管理员账户管理在独立 /super-admin 页面。
- 超级管理员可将普通账号晋升为管理员，支持降级、禁用、启用、重置密码、功能权限与隐藏配置。
- 现有复杂管理员及其他账号保留。新超级管理员用户名为 superAdmin，初始密码按用户指定值通过 SSH 输入，未写入此记录。
- 初始超级管理员、晋升和密码重置后的管理员必须改密码；修改前不能执行管理或业务功能。
- 权限弹窗提供隐藏选项，账号列表提供一键隐藏按钮；普通系统也可切换隐藏未授权入口，偏好按账号保存。
- 未授权导航、菜单和操作按钮可隐藏，包括打包清单；动态渲染的按钮也应用权限状态。
- Nginx 动态查询数据库验证账号和角色，晋升、降级与禁用立即影响后台访问。内部认证不向公网开放。

- Chromium 模拟接口验证 4 组角色与隐藏完整交互；普通登录弹窗 13 组浏览器回归通过。
- Node 代理控制台、权限隐藏、11 项浏览流程及 27 项详情渲染检查通过。
- 服务器执行上述 47 项 Python 检查通过。
- 服务器本机通过真实 Nginx 验证原管理员、新超级管理员初始凭据、首次改密码限制和内部路由保护；没有修改初始超级管理员密码。
